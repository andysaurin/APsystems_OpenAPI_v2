# Screenshots

Add these PNGs to this folder, then uncomment the "Screenshots" section in the top-level `README.md`.

| File | What to capture |
| --- | --- |
| `setup.png` | Settings → Devices & services → Add integration → APsystems OpenAPI (the setup form). Blank or fake the App ID/Secret/SID first |
| `options.png` | The integration's **Configure** dialog, showing the estimated API calls per month |
| `system-device.png` | The `APsystems <SID>` device page with Total Energy, Today Energy and the two buttons |
| `inverter-device.png` | One `Inverter <UID>` device page with its sensors |
| `energy-dashboard.png` | The Energy dashboard using the Total Energy sensor as the solar source |

Use dark or light mode consistently, crop to the card or dialog, and make sure no real App ID, App Secret or System ID is visible.
